Task Manager – Python & Tkinter

Ein einfacher Task Manager mit grafischer Benutzeroberfläche, entwickelt mit Python und Tkinter.

Projektbeschreibung

Dieses Projekt habe ich entwickelt, um meine Python-Kenntnisse praktisch anzuwenden und erste Erfahrungen mit der Entwicklung einer Desktop-Anwendung zu sammeln.

Mit dem Programm können Aufgaben erstellt, verwaltet und dauerhaft gespeichert werden.

Funktionen

* Aufgaben hinzufügen und löschen
* Aufgaben als erledigt markieren
* Prioritäten festlegen: hoch, mittel oder niedrig
* Optionale Fristen mit Datumsprüfung
* Eindeutige Aufgaben-IDs vergeben
* Aufgaben in einer übersichtlichen Tabelle anzeigen
* Daten dauerhaft im JSON-Format speichern

Verwendete Technologien

* Python – Programmlogik
* Tkinter / ttk – Grafische Benutzeroberfläche
* JSON – Lokale Datenspeicherung
* datetime – Prüfung von Fristen
* pathlib – Verwaltung von Dateipfaden
* PyInstaller – Erstellung einer macOS-Anwendung

Installation und Ausführung

Voraussetzung ist eine Python-Installation mit Tkinter-Unterstützung.

Das Programm kann mit folgendem Befehl gestartet werden:

python3 main.py

Alternativ steht eine für macOS erstellte Anwendung zur Verfügung, sofern sie unter GitHub Releases veröffentlicht wurde.

Was ich gelernt habe

Während der Entwicklung habe ich mich insbesondere mit folgenden Themen beschäftigt:

* Funktionen, Listen und Dictionaries
* Eingabevalidierung und Fehlerbehandlung
* Speicherung und Laden von JSON-Dateien
* Entwicklung einer grafischen Benutzeroberfläche

Mögliche Erweiterungen

In Zukunft könnte das Programm um eine Suchfunktion, die Bearbeitung bestehender Aufgaben oder zusätzliche Sortiermöglichkeiten erweitert werden.
